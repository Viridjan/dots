# vj TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace hard-coded desktop/surface machines and flat `.list` files with profiles, dotfile sets and a local config, driven by a Textual TUI (`vj`) that runs the existing bash `vjupdate` as its backend.

**Architecture:** A Python package `vj/` (repo root) owns data: repo TOML (`packages.toml`, `profiles/*.toml`, `projects.toml`), local `~/.config/vjupdate/config.toml`, resolution, estimates. It writes a *run plan* directory (one-name-per-line list files + `env`) that bash reads instead of the old `.list` files. Bash keeps every system action; it gains `--actions`, `VJ_PLAN_DIR`, `_has_feature`, a result file, and stows from `dotsets/<set>/`.

**Tech Stack:** Python 3.14 stdlib (`tomllib`, `unittest`), Textual 8 (`python-textual`, Arch `extra`), bash 5, GNU stow.

**Spec:** `docs/superpowers/specs/2026-10-21-vjupdate-tui-design.md`

## Global Constraints

- Python stdlib only, plus `textual` for the UI module. No other new dependency.
- Local config: `${XDG_CONFIG_HOME:-~/.config}/vjupdate/config.toml`; override path with env `VJ_CONFIG` (tests).
- Writes to `config.toml` and `build-times.tsv` are atomic (`tempfile` in same dir + `os.replace`).
- Resolution: `install = packages.install + profile.install + local.add − local.remove − declined − skip`; `remove = packages.remove + local.remove`; `hold = packages.hold`.
- Estimate buckets: `< 10 s` green `#5fd75f`; `< 1 min` yellow `#ffd75f`; else `~N min` orange `#ff8700`. Guess when no history: paru 3 s, flatpak 10 s, marked `?`.
- Bash: `set -euo pipefail` rules from CLAUDE.md apply; `shellcheck -S warning` clean; never edit `vjupdate` in place while it runs (`pgrep -af vjupdate`) — write temp file + `mv`.
- Tests mock every system command; nothing touches the real system.
- Recap rows show counts/times only, no names.
- The app never commits or pushes.

## Review Focus

1. **Local config missing or partially written** (first run, or user hand-edited and removed a section) → app must load defaults for missing keys, never crash. Test in Task 2.
2. **Profile/dotset named in config no longer exists** (renamed/deleted in repo) → treat as unset, reopen setup panel; bash `vj plan` errors clearly. Test in Task 2 + 4.
3. **Hostname matches no profile and no config** (friend's new machine, `vjupdate --yes`) → bash dies with "run vj to choose a profile", not a stack trace. Test in Task 4.
4. **Package both in repo list and local remove / declined** → never installed, and `remove` only lists local removes + repo removes (declined is *not* removal). Test in Task 3.
5. **Dotset `none`** → no stow at all except `scripts`; DMS import/export skipped with a warning. Test in Task 7.

## File Structure

```
vj/__init__.py          empty
vj/__main__.py          CLI: `python3 -m vj` (TUI) | `python3 -m vj plan DIR`
vj/config.py            repo + local config load/save, TOML writer
vj/resolve.py           resolution, estimates, build-time history, run-plan writer
vj/ui.py                Textual app: Home, Checklist, SetupPanel
packages.toml           common package lists (replaces 5 .list files)
profiles/desktop.toml   desktop packages + features
profiles/surface.toml   surface packages + features
projects.toml           repos to clone (replaces projects.list)
build-times.tsv         committed timing history
dotsets/viridjan/...    all stow packages (git mv)
scripts/.local/bin/vj   launcher
scripts/.local/bin/vjupdate   modified
tests/test_vj.py        Python unit tests (config, resolve, plan, ui)
tests/test_vjupdate.py  modified fixtures + new cases
```

UI is one file (`vj/ui.py`, ~300 lines) rather than the spec's `screens/` folder: three small classes don't earn a package.

### Task 2: `vj/config.py`

**Interfaces — Produces:**
- `DOTS: Path` (repo root = parent of `vj/`)
- `load_repo(dots=DOTS) -> Repo` where `Repo` is a dataclass: `packages: dict`, `profiles: dict[str, dict]`, `projects: list[dict]`, `dotsets: list[str]` (dirs in `dotsets/`), `stow_pkgs(dotset) -> list[str]` (subdirs of the set, excluding names in `profiles`).
- `config_path() -> Path`
- `load_local(path=None) -> dict` — always returns full shape: `{"profile": None, "dotset": None, "paru": {"add": [], "remove": []}, "flatpak": {"add": [], "remove": []}, "declined": {"paru": [], "flatpak": []}, "once": {}, "last": {}}`, merged with file content; missing file → defaults.
- `save_local(cfg, path=None)` — atomic, writes via `dumps(cfg)`.
- `dumps(d: dict) -> str` — minimal TOML writer for str/int/bool/list[str]/date/nested dict (one level of tables + `[last]`/`[once]`); strings via `json.dumps` (valid TOML basic strings).
- `valid_choice(cfg, repo) -> bool` — profile in repo.profiles and (dotset == "none" or in repo.dotsets).

- [ ] Tests (`tests/test_vj.py::ConfigTests`): missing file → defaults; round-trip save/load equals input incl. `once` dates and `last` lists; partial file (`profile = "x"` only) → other keys defaulted; atomic write leaves no temp files; `valid_choice` false for deleted profile and for unknown dotset, true for `none`; `load_repo` on a temp fixture repo lists profiles/dotsets/stow pkgs.
- [ ] Run `python3 -B -m unittest tests.test_vj -v` → fail (no module).
- [ ] Implement.
- [ ] Run → pass. Commit `feat(vj): repo and local config loading`.

### Task 3: `vj/resolve.py` — resolution + estimates

**Interfaces — Consumes:** `Repo`, local cfg dict. **Produces:**
- `resolve(repo, cfg) -> dict` with keys `paru_install, flatpak_install, paru_remove, paru_hold, paru_skip` (ordered, de-duplicated lists).
- `features(repo, cfg) -> list[str]`

- `write_plan(repo, cfg, outdir, stow_selected=None, repos_selected=None)` — writes `paru-install.list paru-remove.list paru-hold.list paru-skip.list flatpak-install.list projects.list stow.list env`. `env` lines: `VJ_PROFILE=… VJ_DOTSET=… VJ_DOTSET_DIR=… VJ_FEATURES='a b'`, values `shlex.quote`d.

### Task 9: TUI (`vj/ui.py`) + launcher

**Consumes:** everything above. **Produces:** `VjApp(dots, cfg_path)`; `python3 -m vj` runs it.

- Home: `OptionList#menu` rows `f"{label:<24}│ {recap(id)}"` for `maint packages repos dotfiles once dms settings run`; `Vertical#sub` slot; Footer. Keys `r` run, `q` quit. Setup panel auto-opens when `not valid_choice(cfg, repo)` and blocks Esc/run until confirmed.
- Checklist panel (generic): Space, `/` filter, `a` all, `n` none, `d` repo defaults, Esc close; packages adds `+` (Input → `cfg[src]["add"]`) and `x` (toggle `cfg[src]["remove"]`). Every toggle updates cfg in memory, menu recaps refresh. Initial ticks: `cfg.last[key]` else defaults; packages: default ticked unless declined.
- Catalogues: maintenance = routine IDs + `kernels` `pacnew-merge` `manual-steps` (defaults as `_menu_add`); once = `services snapper automount optimize keyboard greeter keyring-pam install-scripts fish claude caveman-code dms-plugins ollama vms` (never pre-ticked; row shows done date / skip; `s` skip, `D` already-done); dms = `dms-import dms-export dotfiles-export` (default off).
- Run: save cfg (`last`, `declined`), `write_plan` to `$XDG_RUNTIME_DIR/vj-<pid>`, build IDs (maintenance + once + dms; plus `install` implied when packages to add/remove exist? no — explicit via maintenance), `with self.suspend(): subprocess.run([vjupdate, "--actions", ids], env=…VJ_PLAN_DIR, VJ_RESULT_FILE)`; then read result file, stamp `once[id] = today` for `action:<id>\tok`, save, notify exit code.
- Launcher `scripts/.local/bin/vj`: `#!/usr/bin/env bash` → `exec env PYTHONPATH="$HOME/Projects/dots" python3 -m vj "$@"`; error if `python3 -c 'import textual'` fails: "install python-textual (pacman -S python-textual)".
- Add `python-textual` to `packages.toml`. Add `vj` to `scripts` KEEP list in CLAUDE.md docs; re-stow `scripts` (`--no-folding`).
- [ ] Tests (`UiTests`, Textual `run_test()` without `size=`; each test wrapped in `asyncio.wait_for(…, 20)`): first run opens setup panel; Enter saves profile; packages untick → declined recorded + recap row text updates; run with stubbed `subprocess.run` writes plan + calls `--actions` with expected IDs; result file `action:fish\tok` stamps `once.fish`.
- [ ] Implement, pass. Commit `feat(vj): Textual TUI`.
