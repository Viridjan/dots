# sysup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `vjupdate` + the `vj` Textual TUI with one CLI, `sysup`, plus a stdlib-only Python helper, and add two rotating per-dotset backups.

**Architecture:** `scripts/.local/bin/sysup` (bash, renamed vjupdate) keeps every phase/action. All TOML work moves to one file, `scripts/.local/lib/sysup/sysup.py`, called via `_py`. TUI jobs become flags (`--profile --pkg --status --skip-once --restore`). Backups are local git tags `backup/<set>/{1,2}` on snapshot commits built with a temp index.

**Tech Stack:** bash 5, Python 3.13 stdlib (`tomllib`), git, jq, GNU stow; tests: `unittest` with mocked system commands.

**Spec:** `docs/superpowers/specs/2026-11-07-sysup-design.md`

## Global Constraints

- Never edit the running script in place: write `sysup.new`, then `mv` (check `pgrep -fa bin/sysup`).
- `shellcheck -S warning scripts/.local/bin/sysup` clean; `bash -n` clean.
- `sysup.py` is stdlib only; no `vj` import anywhere after Task 6.
- Phases, `MENU_ORDER` IDs, stamps dir `~/.local/state/dots`, package resolution, post-run fixes, update check, DMS restart: behaviour unchanged.
- Backup tags are never pushed; a backup failure warns and never blocks the save.
- Config migration never overwrites an existing `~/.config/sysup/config.toml`.

## Review Focus

- Machine with an old `~/.config/vjupdate/config.toml` and no new one: first run moves it, profile/dotset kept (test in Task 2).
- `--pkg profile X` with no profile chosen: clear error, nothing written (Task 3).
- `--restore` when no backup tag exists yet: message, nothing changed (Task 5).
- Backup on a repo with uncommitted changes outside the dotset: snapshot holds HEAD's version there, working tree untouched (Task 5).
- Surface after `git pull` with only the dead `vjupdate` link: `sysup` by full path works and relinks (Task 6 runbook; verified by `--actions stow-symlinks` test that prunes dead links, existing).

```python
def migrate_config() -> str:
    """Move the pre-sysup config once. Returns a message or ''."""
    new = config_path()
    if os.environ.get("SYSUP_CONFIG") or new.exists():
        return ""
    old = new.parent.parent / "vjupdate/config.toml"
    if not old.exists():
        return ""
    new.parent.mkdir(parents=True, exist_ok=True)
    os.replace(old, new)
    cfg = load_local(new)
    last = cfg.pop("last", {})
    sel = {k: last[k] for k in ("dotfiles", "repos") if k in last}
    if sel:
        cfg["select"] = sel
    save_local(cfg, new)
    return f"moved {old} → {new}"
```

### Task 5: dotset backups + `--restore`

```bash
# backup/<set>/1 (newest) and /2: local tags on snapshot commits of the
# repo with the set's working-tree state. Never pushed.
_backup_dotset() {   # [live-dms] [reason]
    local mode="${1:-}" why="${2:-save}" set idx tree commit prev f rel
    [[ -n "${SYSUP_DOTSET_DIR:-}" ]] && ! $DRY_RUN || return 0
    set=${SYSUP_DOTSET_DIR##*/}
    git -C "$DOTS_DIR" rev-parse -q --verify HEAD >/dev/null || return 0
    idx=$(mktemp) || return 0
    {
        GIT_INDEX_FILE=$idx git -C "$DOTS_DIR" read-tree HEAD &&
        GIT_INDEX_FILE=$idx git -C "$DOTS_DIR" add -A -- "dotsets/$set" &&
        if [[ "$mode" == live-dms ]]; then
            for f in "$HOME/.config/niri/dms/"*.kdl; do
                [[ -f "$f" && ! -L "$f" ]] || continue
                rel="dotsets/$set/niri/.config/niri/dms/${f##*/}"
                GIT_INDEX_FILE=$idx git -C "$DOTS_DIR" update-index --add --cacheinfo \
                    "100644,$(git -C "$DOTS_DIR" hash-object -w -- "$f"),$rel" || exit 1
            done
        fi &&
        tree=$(GIT_INDEX_FILE=$idx git -C "$DOTS_DIR" write-tree)
    } || { rm -f "$idx"; warn "dotset backup failed — continuing without it"; return 0; }
    rm -f "$idx"
    prev=$(git -C "$DOTS_DIR" rev-parse -q --verify "backup/$set/1^{tree}" 2>/dev/null) || prev=""
    [[ "$tree" != "$prev" ]] || return 0
    commit=$(git -C "$DOTS_DIR" commit-tree "$tree" -p HEAD -m "sysup backup $set $(date '+%F %T') before $why") \
        || { warn "dotset backup failed — continuing without it"; return 0; }
    if git -C "$DOTS_DIR" rev-parse -q --verify "backup/$set/1" >/dev/null; then
        git -C "$DOTS_DIR" tag -f "backup/$set/2" "backup/$set/1" >/dev/null
    fi
    git -C "$DOTS_DIR" tag -f "backup/$set/1" "$commit" >/dev/null && ok "dotset backup: backup/$set/1 ($why)"
}
```

(The `exit 1` inside `{ }` runs in the current shell — use a flag variable instead in the real code.)

Calls: first line of `deploy_dotfiles` (`_backup_dotset "" deploy`), `dms_import` (`_backup_dotset live-dms dms-import`), `export_dotfiles` before staging (`_backup_dotset "" export`).

`--restore N` (N in 1|2): `_ensure_plan`, `_init_runtime`, check tag exists else `die "no backup/<set>/N yet"`; show `git diff --stat backup/$set/$N -- dotsets/$set`; `_confirm "Restore dotsets/$set from backup $N? [y/N]"`; `_backup_dotset "" restore` (only when N=2 or the working tree differs; restoring 1 after the snapshot would point at the fresh snapshot — so resolve the target commit **before** snapshotting); `git checkout <commit> -- dotsets/$set`; hint `sysup --dms-import`.

`--status` (sysup.py) lists `git for-each-ref refs/tags/backup/<set>/ --format='%(refname:short) %(creatordate:short) %(subject)'` — done in bash after `_py status` to keep git out of Python.
